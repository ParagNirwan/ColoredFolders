# ColoredFolders

A Windows desktop utility built with C# and Windows Forms for working with folder colors.

## Build

1. Install Visual Studio with the .NET desktop development workload.
2. Open `ColoredFolders.sln`.
3. Restore NuGet packages and build the solution.

Review the project file for the target .NET Framework and other prerequisites.

## Project notes

This is a desktop utility project. Before distributing it, test on a clean Windows environment and remove machine-specific paths and generated build output from version control.
